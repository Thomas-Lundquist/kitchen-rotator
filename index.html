Kitchen Rotation Tool

Runs in this browser only. Nothing leaves this computer.

Extra duties

Tick the blocks each duty applies to. Duties move one kitchen along every time that block advances.

Job titles

Job titles belong to the seat, not the student. Whoever rotates into the first seat holds the first job that day. A kitchen of 3 uses only the first 3 titles; the jobs below that read SPLIT, meaning the whole kitchen shares that work.

Backup & restore

Everything lives only in this browser. Download a backup file now and then, especially before a big roster change — it's the only way to recover if this browser's storage is ever cleared.

Import roster

Upload a CSV attendance export and the Student column is found for you, or paste names below, one per line. "Archer, Kelly Noel" becomes "Kelly A." A plain first name is used as written. Names are shuffled and split as evenly as possible, 4 to a kitchen where the numbers allow. This replaces the roster for this block and resets its duty rotation.
