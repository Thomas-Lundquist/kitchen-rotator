Kitchen Rotation Tool

Rotates students through kitchen seats, jobs, and duties.

Extra duties

Tick the blocks each duty applies to. Duties move one kitchen per rotation. A kitchen never repeats a duty within a day, since the next period works the same station.

Job titles

Titles belong to the seat, not the student. A kitchen smaller than this list shows SPLIT for the leftover jobs, which the whole kitchen shares.

Backup & restore

Data lives only in this browser. A backup file is the only way to recover it if this browser’s storage is cleared.

Import roster

Upload a CSV attendance export and the Student column is found for you, or paste names below, one per line. "Archer, Kelly Noel" becomes "Kelly A." A plain first name is used as written. Names are shuffled and split as evenly as possible, 4 to a kitchen where the numbers allow. This replaces the roster for this block and resets its duty rotation.
